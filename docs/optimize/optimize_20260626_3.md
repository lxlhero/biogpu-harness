# Phase 2.1-B：实现 log_event.py

进入 Phase 2.1-B，只做事件日志脚本：

```text
scripts/log_event.py
```

不要做：

```text
compare_precision.py
hooks
CI
rjob_submit.py
dashboard
真实工具工作区修改
```

## 1. 目标

实现一个稳定的事件日志脚本，把 command / agent 的关键事件追加写入：

```text
<workspace>/logs/events.jsonl
```

它用于后续：

```text
B 模式恢复上下文
existing-project-planner 判断历史状态
Completed Gate
hooks
dashboard
```

## 2. 调用方式

支持命令行参数：

```bash
python scripts/log_event.py \
  --workspace /Users/huron/code/ai_lab/transfer2gpu/_phase2_dryrun_tool \
  --agent bio-gpu-team \
  --event-type dry_run_completed \
  --status pass \
  --step phase2_1 \
  --message "Phase 2.1-B log_event smoke test"
```

也支持 JSON 文件：

```bash
python scripts/log_event.py \
  --workspace /Users/huron/code/ai_lab/transfer2gpu/_phase2_dryrun_tool \
  --event-json /tmp/event.json
```

## 3. 自动补全字段

脚本应从 workspace 中读取：

```text
biogpu_project.yaml
state/task_state.json
```

并自动补全：

```text
timestamp
tool_name
task_id
mode
current_step
next_action
attempt
```

如果某些字段缺失，可以 warning，但不能写出非法 JSON。

## 4. 写入格式

每一行是一个 JSON object，例如：

```json
{
  "timestamp": "2026-06-26T10:30:00+08:00",
  "tool_name": "_phase2_dryrun_tool",
  "task_id": "_phase2_dryrun_tool_20260626",
  "mode": "B",
  "agent": "bio-gpu-team",
  "event_type": "dry_run_completed",
  "status": "pass",
  "step": "phase2_1",
  "module": null,
  "attempt": 0,
  "artifact_path": null,
  "next_action": "manual_review",
  "message": "Phase 2.1-B log_event smoke test"
}
```

## 5. event_type 白名单

先支持：

```text
project_initialized
source_setup_completed
benchmark_designed
profiling_completed
feasibility_completed
test_plan_created
test_started
test_completed
test_failed
implementation_started
implementation_completed
review_completed
module_test_completed
failure_diagnosed
execution_plan_created
final_report_written
blocked
manual_approval_required
dry_run_completed
```

未知 `event_type` 直接 fail。

## 6. status 白名单

合法值：

```text
pass
fail
running
blocked
warning
info
```

未知 `status` 直接 fail。

## 7. 写入规则

必须保证：

```text
1. 写入 <workspace>/logs/events.jsonl
2. 自动创建 logs/ 目录
3. append 写入，不覆盖
4. 每行必须是合法 JSON
5. 不允许写入 HARNESS_ROOT
6. workspace 不能是 /Users/huron/code/ai_lab/biogpu-harness
7. workspace 不能在 HARNESS_ROOT 下面
8. 写入前调用 validators 检查：
   python scripts/validate_biogpu_project.py --workspace <workspace>
   python scripts/validate_task_state.py --workspace <workspace>
```

## 8. 输出格式

成功输出：

```json
{
  "status": "pass",
  "event_file": "/Users/huron/code/ai_lab/transfer2gpu/_phase2_dryrun_tool/logs/events.jsonl",
  "event_type": "dry_run_completed",
  "errors": [],
  "warnings": []
}
```

失败输出：

```json
{
  "status": "fail",
  "errors": [
    {
      "field": "workspace",
      "message": "workspace must not be HARNESS_ROOT or inside HARNESS_ROOT"
    }
  ],
  "warnings": []
}
```

退出码：

```text
pass: 0
validation fail: 1
script error: 2
```
