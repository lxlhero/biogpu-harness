## 3. 新增 init_trace_context.py

新增脚本：

```text
scripts/init_trace_context.py
```

作用：为某个 workspace 创建或刷新当前 session 的 trace context。

支持调用：

```bash
/Users/huron/miniconda3/envs/biogpu-harness/bin/python scripts/init_trace_context.py \
  --workspace /Users/huron/code/ai_lab/transfer2gpu/_phase2_dryrun_tool \
  --created-by bio-gpu-team
```

必须读取：

```text
<workspace>/biogpu_project.yaml
<workspace>/state/task_state.json
```

并写入：

```text
<workspace>/state/trace_context.json
```

生成字段：

```json
{
  "task_id": "_phase2_dryrun_tool_20260626",
  "tool_name": "_phase2_dryrun_tool",
  "session_id": "sess_20260626_140000_xxxxxx",
  "trace_id": "trace__phase2_dryrun_tool_20260626_140000_xxxxxx",
  "root_span_id": "span_bio_gpu_team_20260626_140000_xxxxxx",
  "current_span_id": "span_bio_gpu_team_20260626_140000_xxxxxx",
  "created_at": "2026-06-26T14:00:00+08:00",
  "created_by": "bio-gpu-team",
  "updated_at": "2026-06-26T14:00:00+08:00",
  "notes": ""
}
```

规则：

```text
1. 每次 /bio-gpu-team 新启动一个用户请求，应创建新的 session_id 和 trace_id。
2. task_id 可以继承 task_state.json。
3. tool_name 可以继承 biogpu_project.yaml。
4. root_span_id 默认属于 bio-gpu-team。
5. 不允许写入 HARNESS_ROOT。
6. 写入前运行 validate_biogpu_project.py 和 validate_task_state.py。
```

退出码：

```text
pass: 0
validation fail: 1
script error: 2
```

## 4. 升级 log_event.py

更新：

```text
scripts/log_event.py
```

在保持旧接口兼容的基础上，新增 tracing 字段支持。

### 4.1 新增支持参数

```bash
--trace-id
--session-id
--span-id
--parent-span-id
--decision-id
--command-id
--artifact-id
--artifact-path
--command
--exit-code
```

旧调用方式仍然可用。

### 4.2 自动读取 trace_context.json

如果用户没有显式传：

```text
trace_id
session_id
span_id
parent_span_id
```

则从：

```text
<workspace>/state/trace_context.json
```

自动补全。

如果 trace_context.json 不存在：

```text
1. 不要静默乱写。
2. 返回 fail。
3. 提示先运行 scripts/init_trace_context.py。
```

### 4.3 新 events.jsonl 标准格式

每条 event 至少包含：

```json
{
  "event_id": "evt_20260626_140000_xxxxxx",
  "timestamp": "2026-06-26T14:00:00+08:00",
  "tool_name": "_phase2_dryrun_tool",
  "task_id": "_phase2_dryrun_tool_20260626",
  "session_id": "sess_20260626_140000_xxxxxx",
  "trace_id": "trace__phase2_dryrun_tool_20260626_140000_xxxxxx",
  "span_id": "span_bio_gpu_team_20260626_140000_xxxxxx",
  "parent_span_id": null,
  "agent": "bio-gpu-team",
  "event_type": "dry_run_completed",
  "status": "pass",
  "step": "phase2_2_tracing",
  "module": null,
  "attempt": 0,
  "decision_id": null,
  "command_id": null,
  "artifact_id": null,
  "artifact_path": null,
  "command": null,
  "exit_code": null,
  "next_action": "manual_review",
  "message": "Phase 2.2-A tracing smoke test"
}
```

### 4.4 新增 event_type

在原有 event_type 白名单基础上，新增：

```text
trace_context_created
decision_made
command_executed
artifact_created
artifact_updated
state_updated
gate_checked
trace_analysis_requested
```

### 4.5 artifact_path 和 artifact_id 规则

如果传入：

```text
--artifact-path reports/test_results/primary_e2e_precision.json
```

可以自动生成：

```text
artifact_id: art_primary_e2e_precision_json_<short_id>
```

如果用户显式传 `--artifact-id`，优先使用用户传入的。
