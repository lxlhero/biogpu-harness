
## 二、核心宪法原则

新增文件：

```text
docs/architecture/resource_layer_constitution.md
```

这个文件是 `knowledge/` 与 `skills/` 的最高级定位说明。后续所有整理都必须以它为准。

### 2.1 commands 定位

`.claude/commands/` 是用户入口层。

只负责：

```text
1. 接收用户调用
2. 询问少量业务信息
3. 判断 A/B 模式
4. 创建或读取项目配置
5. 路由到对应 agent
6. 展示 human approval gate
```

不负责：

```text
1. 不做 benchmark 设计
2. 不做 profiling
3. 不判断 precision metrics
4. 不下载源码
5. 不跑测试
6. 不写复杂报告
7. 不直接读取 skills 长方法论
```

正式 commands 只保留：

```text
.claude/commands/bio-gpu-team.md
.claude/commands/bio-gpu-project-init.md
```

可选保留：

```text
.claude/commands/gpu-team.md
```

但只能作为 deprecated redirect。

---

### 2.2 agents 定位

`.claude/agents/` 是专业执行角色层。

agents 负责：

```text
1. 读取 biogpu_project.yaml
2. 读取 state/task_state.json
3. 执行专业任务
4. 按需读取 knowledge / skills
5. 写 reports/runs/baseline/logs/artifacts
6. 更新 task_state.next_action
7. 返回短摘要给 /bio-gpu-team
```

agents 不负责：

```text
1. 不做人类总入口
2. 不重写总流程
3. 不绕过 task_state 自己跳步骤
4. 不把长日志贴回主对话
5. 不把 runtime artifact 写进 biogpu-harness
6. 不复制长方法论正文到 agent 文件里
```

每个 agent 必须明确：

```text
Always read:
  高频运行时文件

Read on demand:
  长方法论 / 模板资产

Never:
  不该读取或不该承担的职责
```

---

### 2.3 knowledge 定位

`.claude/knowledge/` 是运行时短知识库。

只允许放：

```text
1. 高频必读短规则
2. 执行硬约束
3. pitfall checklist
4. failure quick diagnosis
5. reviewer / tester / problem analyst 必查规则
6. 会直接影响 next_action 的判断规则
```

不允许放：

```text
1. 长篇 GPU 化方法论
2. 完整 benchmark 教程
3. 完整 validation metrics 教程
4. 报告模板
5. 历史迁移记录
6. 用户说明
7. runtime artifacts
```

定位一句话：

```text
knowledge = agents 的随身短手册
```

## 十二、Step 9：文件处理决策规则

根据 audit 表，对每个文件标记：

```text
keep
move
merge
internalize
delete
archive
split
```

### 12.1 keep

保留文件。

适用：

```text
1. 定位清楚
2. 有明确 consumer
3. 内容不重复
4. 路径正确
```

### 12.2 move

移动到正确目录。

例子：

```text
短 checklist 在 skills/references/
→ 移到 .claude/knowledge/

长方法论在 knowledge/
→ 移到 skills/.../references/
```

### 12.3 merge

合并重复文件。

例子：

```text
knowledge/methodology.md 与 bottleneck_analysis.md 重叠
→ knowledge 保留摘要
→ 长版保留在 skills/references/bottleneck_analysis.md
```

### 12.4 internalize

内容只服务单个 agent，就内化进 agent。

例子：

```text
某段只告诉 test-planner 如何写 test_plan
→ 内化进 bio-gpu-test-planner-agent.md
```

### 12.5 delete

删除无价值文件。

适用：

```text
1. 过时
2. 无 consumer
3. 内容重复
4. 没有未来价值
5. 保留会误导
```

### 12.6 archive

历史有价值但不该被正式调用。

归档到：

```text
docs/archive/
```

例如：

```text
skills/bioinformatics-tool-gpu-skills/SKILL.md.bak_20260624
```

建议：

```text
delete 或移入 docs/archive/
```
