# BioGPU-Harness Phase 2.0：工程化前置收尾方案

> 目标：在进入 Phase 2.1 基础脚本实现之前，先完成控制面一致性检查、示例同步、路径清理、审计表确认和 B 模式 dry-run。
> 本阶段不实现 hooks、CI、schema、log_event.py、compare_precision.py。
> 本阶段只做工程化前置收尾，确保 Phase 2.1 不会踩第一阶段遗留问题。

---

## 一、Phase 2.0 总目标

Phase 2.0 要回答一个问题：

```text
第一阶段控制面重构是否已经足够干净，可以开始写工程化脚本？
```

需要确认：

```text
1. 旧路径已经彻底清除。
2. example 配置已经同步新字段。
3. knowledge / skills 审计表没有明显遗漏。
4. agents / commands 的资源层引用没有断链。
5. B 模式 session_request 链路格式稳定。
6. 没有 runtime artifacts 写入 biogpu-harness。
```

---

## 二、本阶段不做什么

本阶段不要做：

```text
1. 不实现 scripts/log_event.py。
2. 不实现 scripts/compare_precision.py。
3. 不实现 scripts/rjob_submit.py。
4. 不实现 schema。
5. 不实现 hooks。
6. 不实现 CI。
7. 不做 dashboard。
8. 不做 Python package 化。
9. 不修改真实 transfer2gpu/<tool> 工作区。
10. 不重写 agent 大逻辑。
```

本阶段只做：

```text
检查
同步示例
修小路径问题
补审计缺口
做 dry-run 验证
输出 Phase 2.0 报告
```

```text
1. 不运行真实 benchmark。
2. 不下载真实源码。
3. 不提交 rjob。

5. 只创建或使用 _phase2_dryrun_tool 临时工作区。
6. 如果创建了临时工作区，报告中说明路径。
```

dry-run 后检查：

