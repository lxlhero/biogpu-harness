## 10. Smoke test：保留 negative case，同时新增 clean case

使用：

```text
/Users/huron/code/ai_lab/transfer2gpu/_phase2_dryrun_tool
```

注意：当前 dry-run workspace 中保留了 Phase 2.2-B 注入的异常事件：

```text
test_completed pass
artifact_path = reports/test_results/missing_precision.json
但该 artifact 实际不存在
```

这个异常不要删除。它用于验证 gate 能发现证据链不一致，并正确路由给：

```text
bio-gpu-trace-analyst-agent
```

因此本阶段 smoke test 必须分成两组：

```text
1. negative test：保留异常事件，确认 primary_e2e gate fail，并路由 trace analyst
2. clean test：新增一个干净 test_suite，确认 primary_e2e gate pass
```

---

### 10.1 Negative test：保留异常事件

不要删除或修改已有异常事件。

执行：

```bash
/Users/huron/miniconda3/envs/biogpu-harness/bin/python scripts/check_completion_gate.py \
  --workspace /Users/huron/code/ai_lab/transfer2gpu/_phase2_dryrun_tool \
  --gate primary_e2e \
  --test-suite phase2_1
```

期望结果：

```text
fail exit 1
recommended_next_agent = bio-gpu-trace-analyst-agent
reason = evidence chain inconsistent / event artifact_path missing
```

这说明 gate 能识别：

```text
event status=pass
但 artifact_path 指向的文件不存在
```

并且没有误判为通过。

---

### 10.2 Clean test：新增干净 test_suite

为了验证正常路径也能 pass，不要清理 negative event，而是新增一个独立干净 test suite：

```text
phase2_2_clean
```

创建或确认以下文件存在：

```text
reports/test_plans/phase2_2_clean_test_plan.md
reports/test_results/phase2_2_clean_precision.json
reports/test_results/phase2_2_clean_precision.md
```

`phase2_2_clean_test_plan.md` 必须包含合法 `precision_config`，例如：

```yaml
precision_config:
  test_suite: phase2_2_clean
  metrics:
    - name: pearson
      cpu_file: baseline/phase2_1/cpu_scores.tsv
      gpu_file: runs/phase2_1/gpu_scores.tsv
      key_column: id
      value_column: score
      threshold: 0.99
      direction: ">="
```

`phase2_2_clean_precision.json` 至少包含：

```json
{
  "status": "pass",
  "test_suite": "phase2_2_clean",
  "metrics": [
    {
      "name": "pearson",
      "value": 0.9999,
      "threshold": 0.99,
      "direction": ">=",
      "status": "pass"
    }
  ],
  "failed_metrics": [],
  "errors": []
}
```

然后用 `log_event.py` 写入一条干净的 pass event：

```bash
/Users/huron/miniconda3/envs/biogpu-harness/bin/python scripts/log_event.py \
  --workspace /Users/huron/code/ai_lab/transfer2gpu/_phase2_dryrun_tool \
  --agent bio-gpu-test-runner-agent \
  --event-type test_completed \
  --status pass \
  --step phase2_2_clean \
  --artifact-path reports/test_results/phase2_2_clean_precision.json \
  --message "Phase 2.2-D clean primary_e2e smoke test"
```

再执行：

```bash
/Users/huron/miniconda3/envs/biogpu-harness/bin/python scripts/check_completion_gate.py \
  --workspace /Users/huron/code/ai_lab/transfer2gpu/_phase2_dryrun_tool \
  --gate primary_e2e \
  --test-suite phase2_2_clean
```

期望结果：

```text
pass exit 0
```

### 10.5 smoke test 验收要求

Phase 2.2-D 完成后必须同时满足：

```text
1. phase2_1 negative test 保留，primary_e2e gate fail。
2. phase2_1 negative test 正确路由到 bio-gpu-trace-analyst-agent。
3. phase2_2_clean clean test 新增，primary_e2e gate pass。
4. project_init gate pass。
5. test_plan gate pass。
6. events.jsonl 中同时保留 negative evidence 和 clean evidence。
7. 不删除 Phase 2.2-B 注入的异常事件。
```

如果 Claude Code 为了让所有测试 pass 而删除 negative event，视为不通过。
