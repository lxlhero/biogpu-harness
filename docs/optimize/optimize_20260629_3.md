## 1. log_event.py 接入 event.schema.json

更新：

```text
scripts/log_event.py
```

要求：

1. 构造 event object 后，先用：

```text
schemas/event.schema.json
```

做 schema 校验。

2. schema pass 后，才追加写入：

```text
<workspace>/logs/events.jsonl
```

3. schema fail 时：

```text
不写 events.jsonl
exit 1
输出 schema_errors
```

4. 原有自定义逻辑继续保留：

```text
workspace 不能是 HARNESS_ROOT
trace_context.json 必须存在
event_type / status 白名单继续保留
```

---

## 2. init_trace_context.py 接入 trace_context.schema.json

更新：

```text
scripts/init_trace_context.py
```

要求：

1. 生成 trace_context object 后，先用：

```text
schemas/trace_context.schema.json
```

校验。

2. schema pass 后写入：

```text
<workspace>/state/trace_context.json
```

3. schema fail 时不写入，exit 1。

4. 原有逻辑继续保留：

```text
读取 biogpu_project.yaml
读取 task_state.json
不允许写入 HARNESS_ROOT
生成 session_id / trace_id / root_span_id / current_span_id
```

---

## 3. compare_precision.py 接入 precision_config.schema.json

更新：

```text
scripts/compare_precision.py
```

要求：

1. 从 test_plan markdown 中提取 `precision_config` 后，先用：

```text
schemas/precision_config.schema.json
```

校验。

2. schema pass 后，再执行 metric 计算。

3. schema fail 时：

```text
不执行 metric
exit 2
输出 schema_errors
```

4. 原有自定义 metric 检查继续保留：

```text
pearson/spearman 必须有 value_column
jaccard 必须有 key_column
ratio 必须有 threshold_low / threshold_high
file_exists 必须有 file 或 gpu_file
```
