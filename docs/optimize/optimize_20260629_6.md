## 1. CI 目标

CI 需要自动检查：

```text
1. schemas 是否可解析
2. validators 是否能通过 dry-run workspace
3. hook_validate_file.py 是否能检查关键文件
4. compare_precision.py 是否能跑 pass/fail/error 样例
5. check_completion_gate.py 是否能跑核心 gate
6. active 文件中是否还有旧路径
7. agents / commands 基础结构是否完整
```

CI 不跑真实 GPU 加速，只检查 BioGPU-Harness 本身是否健康。

## 4. CI 输出格式

```json

  "status": "pass",

    {
      "name": "schema_parse",

    {
      "name": "validators",
      "status": "pass"
    }

  "warnings": []

  "status": "fail",
  "checks": [
    {
      "name": "validators",
      "status": "fail",
      "message": "validate_task_state.py failed"
    }
  ],
  "errors": [],
  "warnings": []
}
```

退出码：

```text
pass: 0
CI fail: 1
script error: 2
```

## 5. 可选：GitHub Actions

如果当前仓库已经使用 GitHub，可以新增：

```text
.github/workflows/harness-ci.yml
```

最小 workflow：

```yaml
name: BioGPU-Harness CI

on:
  push:
  pull_request:

jobs:
  harness-ci:
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4
      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install pyyaml jsonschema numpy pandas scipy
      - name: Run harness CI
        run: |
          python scripts/run_harness_ci.py
```

如果 GitHub Actions 暂时不方便跑本地绝对路径 workspace，可以先不加 workflow，只实现本地 CI 脚本。
