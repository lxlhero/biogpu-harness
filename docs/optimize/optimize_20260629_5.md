## 4. 优化 hook_validate_file.py 的鲁棒性

检查并补强：

```text
1. stdin JSON 缺少 tool_input.file_path 时，不要崩溃
2. 多文件输入时尽量逐个校验，或明确只校验当前 file_path
3. 非关键文件必须 skipped exit 0
4. 文件不存在时，如果是删除操作，应输出 warning 或 skipped，不要误报 script error
5. 所有输出保持 JSON
```
