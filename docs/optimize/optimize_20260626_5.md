## 4. 更新 bio-gpu-test-planner-agent

文件：

```text
.claude/agents/bio-gpu-test-planner-agent.md
```

新增硬规则：

test plan 必须包含机器可读 YAML block：

```yaml
precision_config:
  test_suite: primary_e2e
  metrics:
    - name: pearson
      cpu_file: baseline/primary_e2e/normalized_cpu_scores.tsv
      gpu_file: runs/primary_e2e/normalized_gpu_scores.tsv
      key_column: gene_id
      value_column: score
      threshold: 0.99
      direction: ">="
```

说明：

```text
compare_precision.py 依赖 precision_config。
如果 test_plan 没有 precision_config，test-runner 必须 blocked。
```

明确边界：

```text
test-planner-agent 决定 metric / threshold / direction。
compare_precision.py 只执行 precision_config，不决定精度策略。
```

